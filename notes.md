# Notes for development
## Adjustable settings
- toggles
    - arp/strum
    - chord/notes
    - hold/instant (whether chord stays playing after releasing)
    - (midi/synth/both)
- arp
    - subdivision
    - style (Up, Down, UpDown, DownUp, Converge, Diverge, Random)
- strum
    - amount
    - style (up, down, random)
- global
    - bpm
    - key
    - scale (maj, min)
    - default velocity
    - random velocity amount
    - octave
